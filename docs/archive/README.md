# The archive

Notes kept as they were written, for anyone who needs to know what was known or decided at the time. **Nothing here is current, and nothing here is edited.** What is current lives in README, INSTALL, the manual, CONTRIBUTING and RULINGS.

| File | What it is |
|---|---|
| `HANDOVER_6.md` to `HANDOVER_15.md` | Notes from one working session to the next, 1.29 to 1.64.2. RULINGS.md cites some of them as the place a decision was made. From 17 November 2026, session notes live in issues, pull requests and the team's workflow document instead. |
| `TESTING_1.29.8.md`, `TESTING_1.30.md` | What to check by hand before those two releases |
| `REVIEW_RESPONSE_1.29.4.md` | The answer to the external review of 1.29.4 |
| `stata/` | The Stata guides from before 1.36, marked as retired. Kept so that a past field report can be read against what the user was told at the time. |

The source archive on PyPI does not carry this folder (MANIFEST.in).
